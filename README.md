# LIQUID247 运营后台

依据根目录《01-后台需求.md》实现的 /admin 后台前端。所有业务接口与行情探测均由 MSW 在浏览器内模拟，无需后端服务，也不会请求真实交易所。

## 启动

使用 Node.js 22.12+ 或 Node.js 24，首次运行：

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173/admin 。MSW 需要 localhost、127.0.0.1 或 HTTPS 的安全上下文。

| 角色       | 邮箱                 | 演示密码 |
| ---------- | -------------------- | -------- |
| 超级管理员 | admin@liquid247.xyz  | Demo247! |
| 内容管理员 | editor@liquid247.xyz | Demo247! |

新增的内容管理员也使用统一演示密码。后台会话使用独立的 localStorage 键，不与网站前台登录共用。

## 已实现

- 情报工作台：分栏搜索、分页、编辑、保存、发布、定时发布、下架、再发布；发布状态统一为已发布、未发布、已下架；超管删除未发布内容或归档发布过的内容。
- 编辑页：标题、富文本正文、类型、Token、只读发布时间、定时安排、只读点击和收藏、冻结快照、前台内容预览。正文支持标题、加粗、斜体、下划线、删除线、列表、引用、链接、分隔线、清除格式与撤销重做。
- 术语库：搜索、新增、编辑、删除与发布状态。
- 监测池：搜索、启停、加入前探测；模拟成功、失败、超时，探测凭证与品种及交易对绑定。
- 巨鲸名单：维护原始地址、场所、胜率、30 日盈亏；复制原始地址；最近动作取最新关联情报标题。
- 链接数据：新增、编辑、探测、启停；行情密钥仅维护 secret:// 引用。
- 值班总览：统一日期区间、六项指标、PV/UV 趋势、新增注册趋势、类型分布。
- 延迟检测：节点、覆盖、延迟、状态；周期模拟探测、手动探测、阈值和异常策略配置。
- 前台用户：邮箱、数字 ID、昵称搜索；停用恢复、只读偏好与收藏、一次展示的模拟临时密码。
- 后台账号：超管创建、删除、启停内容管理员；配置五个板块授权。
- 操作日志：时间、账号、角色、动作、数字对象 ID、备注及前后状态。

## 模拟数据与权限

数据统一存于 localStorage 的 liquid247:mock-db:v2，修改后刷新仍保留。首次读取旧版 v1 数据时自动迁移，保留旧版存储作为备份，不混淆旧已下架与新未发布。侧栏底部“重置演示数据”可恢复初始状态。账号会话、导航、路由和 Mock 写接口均检查权限；后台账号始终仅超级管理员可用。停用或删除后台账号会清除其模拟会话。

探测、定时发布、密码重置均为演示行为。定时发布使用独立的 scheduled_at，在计划执行前仍为未发布；可调整或取消。time 只记录实际发布时间，执行时更新。定时发布在应用运行期间通过请求触发检查，不是离线服务端定时任务。禁用品种或数据源后对应定时情报暂停自动发布；延迟异常时依据配置决定是否停止自动发布。

演示统计提供近 90 天数据。UV 按文档口径累加每日 UV；活跃用户以结束日回看 30 天，排除停用账号；注册总数累计至结束日。收藏趋势使用模拟的每日新增收藏事件。

未接真实行情、账号服务或数据库。snapshot 更正流程尚未在需求中定义，因此快照只读；待《03-规则.md》补齐后扩展规则细节。

正文以 body_doc（编辑器 JSON）为主数据，body 为自动提取的纯文本。已发布内容使用“保存并更新”直接更新公开内容，保持已发布；下架保存仍为已下架。预览按允许的节点与链接协议渲染。

## 项目结构

- src/app：路由布局、登录会话、权限。
- src/features：业务页面。
- src/components：共用页面、表格、筛选、状态与富文本编辑器。
- src/content：富文本内容规范、纯文本转换与安全预览。
- src/services：请求封装，页面不直接访问模拟仓库。
- src/mocks：种子数据、领域规则、MSW 接口。
- src/types.ts：业务枚举与数据类型。
- e2e：浏览器流程测试。

接真实服务时，保留 services 的调用契约，将 main.tsx 中的 MSW 启动改为只在 Mock 模式运行，并把 api.ts 的请求地址指向真实后台；鉴权、审计、定时任务、密码服务与正式持久化需由服务端实现。

## 验证与构建

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

浏览器测试使用本机 Microsoft Edge（headless）；其他环境可修改 playwright.config.ts 的 channel，或安装 Playwright Chromium。测试自动启动本地服务，已有服务时复用。截图输出至 .artifacts/。

静态部署需让 /admin/* 回退到 index.html，并确保 /mockServiceWorker.js 可直接访问。当前构建仍为 Mock 演示版本。
